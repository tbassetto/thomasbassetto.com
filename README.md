# thomasbassetto.com

One-page personal site built with Astro.

## Commands

| Command             | Action                          |
| :------------------ | :------------------------------ |
| `pnpm install`      | Install dependencies            |
| `pnpm dev`          | Start the local server          |
| `pnpm build`        | Build the production site       |
| `pnpm check`        | Run Astro checks and Oxlint     |
| `pnpm format`       | Format with Oxfmt               |
| `pnpm format:check` | Verify formatting without edits |

The production build includes a sitemap through `@astrojs/sitemap`.
